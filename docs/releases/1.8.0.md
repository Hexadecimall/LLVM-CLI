# LLVM-CLI 1.8.0

The macOS/Apple Silicon prebuild embeds LLVM 23.1.6, including the Clang,
LLD, LLDB, Flang, MLIR, Polly, and BOLT tools. Existing short commands such
as `llvm nm` remain available. The application uses O3, ThinLTO, static
non-system dependencies, and stripped local symbols.

- Updated LLD accepts the newer Darwin text-stub targets, including
  `arm64e.x1-macos`.
- Darwin libc headers and `libSystem` link stubs are embedded. Ordinary
  macOS C/C++ builds no longer need Xcode discovery. Both Apple Silicon
  and Intel Mac C++ target runtimes are embedded.
- `llvm update --check` checks for a newer native release. `llvm update`
  streams and verifies the download before atomically replacing the installed
  command on supported POSIX hosts, using the embedded Python/TLS runtime.
- Incremental build commands retain objects and rebuild changed sources.
- Public build scripts pin the upstream source digest, reuse retained inputs,
  and support a capped build workspace and incremental module packaging.
- Release publication verifies uploaded sizes and hashes while staging only
  one release part at a time. Installation reconstructs one executable.

## Host and target coverage

This release provides a macOS 27+/arm64 application. It can produce macOS,
Linux musl, Windows GNU, and WASI outputs within the documented runtime
coverage. Native Linux and Windows LLVM-CLI applications are still under
development and are **not** included in this release. Intel macOS is a
compilation target, not a separately provided LLVM-CLI host prebuild.

The embedded Darwin resources cover libc and C++ compilation, not Apple's
framework SDKs. Framework applications can explicitly select an appropriate
SDK. Windows hosted C++ and glibc executable linking still require additional
target resources. Explicit unsupported static links fail rather than silently
producing dynamically linked output. See the README and PORTABILITY.md.

## Installation

```sh
curl -fsSL https://raw.githubusercontent.com/Hexadecimall/LLVM-CLI/main/install/install.sh | sh
```

The split download assets are transport parts of the same signed executable.
The installer verifies each part and the assembled executable against the
release manifest. Original LLVM-CLI code uses Apache-2.0 WITH LLVM-exception;
bundled components retain their notices, available through `llvm licenses`.
